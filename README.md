# Sitio de Wayout

Páginas estáticas de [wayout.avanc3.pe](https://wayout.avanc3.pe): qué es la app y cómo anunciarse. También sirve `sponsor.json`, el archivo que la app lee para mostrar patrocinadores y banners; editarlo aquí en GitHub y guardar publica el cambio en unos minutos, sin tocar la app.

Sin build: HTML, CSS y las imágenes. Fuentes Hanken Grotesk y Red Hat Mono (Google Fonts, OFL) e iconos Phosphor Light por CDN.

Los textos de `sponsor.json` van en español. Para la app en inglés, cualquier bloque (el principal, `contact`, cada espacio y cada banner) puede llevar `"en": { ... }` con los mismos campos traducidos; lo que no esté en `en` se muestra en español.
